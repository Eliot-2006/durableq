# Surface brief: DurableQ documentation site (Read mode; simulation page is Operate)

Visitor: engineers and hiring managers checking claims. Job: understand guarantees, mechanism, measured evidence; leave trusting the stated limits. Proof: results.json, docs on GitHub, the deterministic simulation. Constraints: static Astro, no CDN fonts, WCAG AA, 360px.

## Direction contract

THESIS: A measurement report, not a product site. Every number carries its environment and its raw source in the margin; the page refuses the hero-metric / feature-card / gradient-blob arrangement of infra landing pages.

OWN-WORLD: Cool paper ground (graphite in dark), one ink, one indigo accent used only for links, selection and current state. Environment tags are the signature: a bare-process figure and a kind figure never share a colour (slate vs amber tag), so they cannot be read as one setup. System sans for reading, mono only for code, SQL, units and tags. 1px rules, no shadows beyond focus, no cards.

STORY: The reader learns what is guaranteed and what is not, sees the mechanism (lease, fence, attempt) work in a labelled simulation, then reads measurements with environments beside them, and follows links to the raw files.

FIRST VIEWPORT: Left-aligned title and one paragraph at 68ch; to its right (wide screens) an evidence margin; below, the ledger of measured highlights as rows (claim, value, environment tag, source link), plus a compact architecture figure. Primary action: Reliability simulation link and GitHub link in the masthead.
